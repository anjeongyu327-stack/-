# RPG 서버 Skript 패키지

Minecraft **Skript 2.16.2** 용 RPG 서버 스크립트 모음입니다. `scripts/` 폴더의 14개 `.sk` 파일을
서버의 `plugins/Skript/scripts/` 아래에 그대로 복사하면 됩니다. 파일명 앞의 두 자리 숫자(00~13)는
**로드 순서**를 강제하기 위한 것이며(Skript는 scripts 폴더를 이름순으로 로드), 뒤 파일이 앞 파일의
함수를 호출하는 의존관계가 있으므로 접두 번호를 지우거나 순서를 바꾸지 마세요.

## 필요 애드온

**없음.** 모든 파일은 순수 Skript 2.16.2 문법만으로 작성되었습니다. (단, 아래 "알려진 한계"의
일부 항목은 skript-reflect/SkBee 같은 애드온을 추가하면 더 안정적으로 구현할 수 있습니다.)

## 원문과 다르게 처리한 부분 (설계상 불가피했던 부분)

- **"쉬프트+F"**: 바닐라 마인크래프트는 F키 입력을 서버로 전송하지 않습니다(F키의 기본 동작은
  "주손↔보조손 교체"). 따라서 "쉬프트 상태에서 교체키(F) 입력"(`PlayerSwapHandItemsEvent`)으로
  구현했습니다. 다른 키를 원하시면 `13_gui.sk`의 `on swap hand items:` 트리거만 원하는 이벤트로
  교체하면 됩니다.
- **직업 스킬 트리거 5종**: 명세 4번 항목에 "우클릭/좌클릭/쉬프트우클릭/쉬프트/쉬프트좌클릭" 총
  5종이 언급되어 이를 기준으로 슬롯 시스템을 만들었습니다(7번 항목의 "4종" 표기와는 다름).
  직업당 액티브 스킬이 5개를 넘는 경우(예: 마검사 6개)를 위해 `/스킬설정` 명령으로 원하는 스킬을
  원하는 슬롯에 재배정할 수 있습니다.
- **직업 종류 개수**: 최종 요청 문구는 "직업 14종"이라 되어 있으나, 본문에 실제로 채워진 직업은
  13종(일반 8종 + 히든 5종)입니다. 채워주신 13종을 그대로 전부 구현했습니다.
- **마법사/힐러 스킬의 "마력스탯"/"지혜스탯"**: 6번 항목(스탯포인트 시스템)에는 힘/민첩/체력/행운/
  회피 5종만 정의되어 있어 마력·지혜는 별도 투자 스탯이 아닙니다. 두 표기 모두 레벨 비례 값
  (`casterPower = 레벨 × 2`)으로 통일해서 스킬 수치에 반영했습니다. 별도 스탯으로 분리하고 싶으시면
  `06_stats.sk`에 스탯을 추가하고 `09_skills.sk`의 `casterPower()` 호출부만 바꾸면 됩니다.
- **정예/근위 등급의 골드·드롭 수치**: 원문에는 일반 몬스터 100종의 골드/드롭만 명시되어 있고
  정예·근위 전용 수치는 없어, "AI 임의 지정" 허용 범위 내에서 골드는 정예 x2/근위 x3, 드롭 확률은
  정예 +10%p/근위 +20%p로 정했습니다(`11_monsters_tiers.sk` 상단 주석 참고).
- **몬스터 스폰 확률 캐스케이드**: 보스 0.3% → 근위 1.5% → 정예 4% → 일반 리스킨 20% → 바닐라
  유지, 순서로 단일 굴림 처리하여 "한 개체가 여러 종류로 중복 판정되지 않도록" 배타적으로
  설계했습니다. 확률 자체는 AI 임의 지정입니다.

## 테스트 관련 안내

이 코드는 실제 Spigot/Paper + Skript 2.16.2 서버에서 직접 실행 검증을 하지 못한 상태로 작성되었습니다
(현재 세션에는 마인크래프트 서버가 없습니다). 1차 제출본에서 실제 서버 콘솔 로그를 받아 아래 항목들을
전부 수정했습니다 (`set {_x} = y` → `set {_x} to y`, 한 줄 `if 조건: 효과` → 2줄 분리, `;`로 이어 쓴
여러 효과 분리, `open ... with size N` → `with N/9 rows`, GUI `clicked item is X`/`raw slot` →
`index of event-slot` 기반 판정, `attacker of event` → `attacher`, 중첩 루프의 `loop-value` 모호성,
괄호로 묶인 `A or (B and C)` 형태의 조건문 등). 그래도 아래 부분은 서버마다 동작이 다를 수 있어
콘솔 로그를 보면서 추가로 다듬어야 할 수 있습니다.

- 속성(Attribute) 관련 효과: `set the attack damage of %entity% to %number%` — Skript 빌드에 따라
  표현이 `attribute ... of` 형태로 달라질 수 있습니다.
- `set the target of %livingentity% to %entity%` (탱커 "성벽" 도발 효과) — 몬스터 타겟 강제 지정은
  Skript 버전마다 지원 여부가 갈리는 기능이라, 오류가 나면 이 한 줄만 지우거나 주석 처리해도 다른
  기능에는 영향이 없습니다.
- 커스텀 몬스터가 디스폰되지 않게 하려면(청크 언로드/자연 디스폰 방지) 별도의 애드온이나
  플러그인(NoAI/Persistent 태그) 도입을 권장합니다 — 순수 Skript만으로는 완전한 제어가 어렵습니다.
- 강철의 심장(대장간) 시스템의 "강화석/속성석/진화의 결정/룬 재료"는 이름표가 붙은 임의 아이템으로
  판별하도록 구현되어 있습니다. 실제 아이템(레시피 등)은 서버 운영 방침에 맞게 추가해 주세요.
- 오류가 또 발생하면 콘솔에 찍힌 파일명·줄번호·에러 메시지를 그대로 붙여넣어 주시면 바로 이어서
  고쳐드릴 수 있습니다.
